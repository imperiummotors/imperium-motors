# Glass Navigation Specification

## Purpose

The Glass Navigation is the signature element of Imperium Motors.

It should immediately communicate confidence, discretion and refinement.

It should never compete with the page.

It should quietly frame the experience.

---

# Layout

Left

- Hamburger Menu

Centre

- Imperium Crest
- Imperium Motors Wordmark

Right

- Private Enquiry
- Elegant Arrow

---

# Behaviour

Initial State

- Large
- Floating
- White glass
- Soft shadow
- 24px from top

Scrolling

- Shrinks slightly
- Blur increases slightly
- Shadow becomes softer
- Logo remains centred

---

# Mobile

Same philosophy.

Never a different design.

---

# Design Rules

No heavy gradients.

No loud shadows.

No thick borders.

No unnecessary icons.

No visual clutter.

---

# Success Test

When someone first sees the homepage...

They should notice the car.

Then the logo.

Only afterwards should they realise there is navigation.

That is luxury.
