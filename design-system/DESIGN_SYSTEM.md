# IMPERIUM MOTORS DESIGN SYSTEM

---

# Brand Personality

Imperium Motors is a private automotive institution.

Our design language is calm.

Confident.

Architectural.

Editorial.

Timeless.

We never design to impress.

We design to reassure.

---

# Emotional Goals

Every visitor should feel:

- Calm
- Confidence
- Trust
- Curiosity
- Privacy
- Elegance

Never:

- Overwhelmed
- Pressured
- Distracted

---

Almost invisible.

Natural daylight.

# Glass

Glass is used only for:

- Navigation
- Menu
- Floating controls

Never entire pages.

---

# Photography

Photography is more important than animation.

Use:

- White architecture
- Studio lighting
- Macro details
- Carbon fibre
- Leather
- Keys
- Steering wheels
- Atelier moments
- Delivery moments

Avoid:

- Random stock photography
- Oversaturated edits
- Busy backgrounds

---

# Video

Video must be silent.

Elegant.

Purposeful.

No generic luxury footage.

No loud edits.

---

# Components

Every component must answer:

Does this increase trust?

Does this reduce clutter?

Does this improve clarity?

Would Rolls-Royce approve?

Would Pagani approve?

Would Apple approve?

If not...

Redesign.

---

# Final Rule

Luxury is subtraction.

Not addition.
